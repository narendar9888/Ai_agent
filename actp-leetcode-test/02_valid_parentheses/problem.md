# Valid Parentheses

Given a string `s` containing only the characters `(`, `)`, `{`, `}`, `[` and `]`,
determine if the input string is valid.

A valid string has matching opening/closing brackets and properly nested pairs.

Examples:
- `s = "()"` -> `True`
- `s = "()[]{}"` -> `True`
- `s = "(]"` -> `False`
- `s = "([)]"` -> `False`
- `s = "{[]}"` -> `True`
